# Project image provenance

Photographs in `public/images/` for the land and agriculture listings. All are
**CC0 / public domain**, sourced through [Openverse](https://openverse.org)
(the search index run by WordPress). CC0 imposes no attribution requirement —
this file exists so a future maintainer knows where they came from and that
they are safe to keep, not because credit is owed.

They are stock placeholders, not photographs of the actual parcels. Replace
them with site photography before these listings are used in a sales context;
a stock beach standing in for a specific titled parcel is fine as decoration
and misleading as evidence.

Each is centre-cropped to 1600x1000 (16:10, matching the project card) and
saved as JPEG at quality 82.
